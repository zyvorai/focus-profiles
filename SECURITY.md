# Security

Focus Profiles can move other apps' windows (Accessibility), ask Terminal, iTerm2, Safari or Google Chrome to open windows and tabs (Automation), connect a VPN and switch a kube context. It carries one entitlement, `com.apple.security.automation.apple-events`.

Terminal commands in a profile are typed into a new terminal window exactly as written; treat profile files like scripts. Only `http` and `https` URLs are opened.

Report vulnerabilities privately to security@zyvor.dev.

The Focus Profiles source code is private.
